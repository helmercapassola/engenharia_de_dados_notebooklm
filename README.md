## 📖 Miniguia de Estudo

### 🧩 Visão geral
Engenharia de Dados é a área responsável por construir sistemas que coletam, transformam e organizam dados para análise e tomada de decisão.

---

### 🔧 Conceitos principais

- **ETL (Extract, Transform, Load):** processo tradicional de transformação de dados antes do armazenamento  
- **ELT (Extract, Load, Transform):** dados são carregados primeiro e transformados depois  
- **Data Pipeline:** fluxo automatizado que move e processa dados entre sistemas  

---

### 🧪 Tecnologias estudadas

- Python → manipulação e análise de dados  
- SQL → consultas e gestão de bases de dados  
- Databricks → processamento de dados em larga escala  


---

### 📊 Fluxo básico de dados

1. Coleta de dados  
2. Processamento / transformação  
3. Armazenamento  
4. Análise e visualização  

---

### 📌 Glossário

- **Pipeline:** sequência automatizada de processamento de dados  
- **Data Lake:** armazenamento de dados brutos  
- **Data Warehouse:** dados organizados para análise  
- **ETL:** processo de extração, transformação e carga de dados
